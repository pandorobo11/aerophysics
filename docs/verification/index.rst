Appendix: verification
======================

These records show how the implementation was checked: against published
equations and tables, against independent software, and against physical
laws such as conservation of mass and energy. "Verified" means that the code
agrees with the stated evidence within the stated tolerance. Comparisons
with measured physical data, where available, are reported separately and
do not change that status.

``Verified with observations`` means that every acceptance check passes, but
an additional, stricter comparison shows small differences that are kept on
record for review.
