aerophysics
===========

``aerophysics`` provides traceable, vectorized engineering models for
atmospheric and aerodynamic physics. Calculation APIs use SI units and return
Python floats for scalar inputs or float64 NumPy arrays for array-like inputs.

Version 0.3 covers a calorically perfect gas, U.S. Standard Atmosphere 1976,
isentropic compressible flow, normal and oblique shocks, Prandtl–Meyer
expansion, smooth flat-plate boundary layers, integrated flight conditions,
and explicit unit conversions.
